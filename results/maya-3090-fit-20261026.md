# Project Maya on one RTX 3090 (24 GB) + 62 GB RAM + NVMe — can it run a large MoE usefully?

**Short answer: yes, at 128K context with GLM-5.3-Flash Maya-XS (~26 tok/s is plausible, less with only 62 GB RAM); the "1M context on one 3090" claim is real as a *start-up* mechanism, not as a demonstrated useful 1M run on this hardware.**

## 1. What fits, and what single-3090 users actually measured

Your pool is 24 GB VRAM + 62 GB RAM = **86 GB**. Maya counts VRAM + RAM together; what doesn't fit streams from NVMe while it answers (https://raw.githubusercontent.com/mw00/project-maya/main/docs/MEMORY.md — read 2026-11-17).

- **GLM-5.3-Flash Maya-XS (73.4 GB download, ~80 GB whole model, recommended 88 GB = 24 GB GPU + 64 GB RAM at 128K context)** is the fit. At 86 GB you are 2 GB under the recommended figure but above the ~80 GB whole-model figure, so nearly everything can sit in VRAM + RAM with a small SSD spill (same source).
- **Maya-S24 (94.7 GB, recommended 128 GB)** runs but streams a large share from SSD on this box; expect it well below its reported speeds (same source).
- DeepSeek-V4.1-Flash Maya-XS needs 128 GB recommended and its 277 GB download includes Engram tables that stay on SSD; MiniMax Maya-XS also wants 128 GB. Neither fits whole here (same source).

Single-3090 user reports from the README benchmark table (https://github.com/mw00/project-maya — read 2026-11-17; all with far more RAM than 62 GB):

- **@briepala, 1x RTX 3090, 126 GB RAM, Maya-S24, 128K context: 26.0 tok/s decode, 913 tok/s prefill** (v1.1.2, issue #135).
- **@erikash, 1x RTX 3090, 141 GB RAM, Maya-M, 128K context: 27.0 tok/s decode, 1,069 tok/s prefill** (v1.1.4, issue #157).
- **DeepSeek, 1x RTX 3090, 125 GB RAM, Maya-XS: 12.9 → 27.8 tok/s decode at 64K context** after the v1.1.28 single-GPU data-path fix (PR #476), per https://xenospectrum.com/en/project-maya-deepseek-decode-context/ (read 2026-11-17).

No single-3090 report at 62 GB RAM was found: with ~56 GB usable RAM (Maya pins all but ~6 GB; README "Install" section, same GitHub link) more experts spill to SSD, so expect **below 26 tok/s** — how far below is unmeasured. An independent 2x 3090 run (96 GB RAM, Maya-S24) held ~47–50 tok/s flat to 100K context: https://andy.cm64.io/blog/glm53-flash-dual-3090-maya (read 2026-11-17).

## 2. Is the "1M context on one 3090" X claim real?

The claim as given in the brief (@JoeGuglielmucci, 2026-10-25): *"KV history in RAM, recent window in VRAM -> 1M context fits a single 3090."* I could not fetch the X post itself (x.com is blocked for fetching here), so the wording is quoted from the brief, not independently verified.

The mechanism behind it is real and documented: since v1.1.6, above 32K context Maya streams the attention latent through pinned RAM and keeps a 32K window in VRAM. The v1.1.6 release notes, as reported at https://vramcalculator.com/project-maya-glm-5-3-flash/ (read 2026-11-17), say that on one RTX 3090 at 512K, KV streaming raised the expert cache from 714 to 1,176 slots and *"1M of context then starts on one RTX 3090, which it does not without streaming."* GLM's KV cache is also small — about 0.2 GB at 32K, kept in RAM (MEMORY.md link above) — so a 1M KV cache is on the order of ~6 GB in RAM, affordable here.

But "starts" is not "runs usefully": **no user report of a single 3090 actually running a 1M context was found.** Every 1M row in the README table is multi-GPU or an 80–96 GB card (e.g. 2x H100, 122 tok/s; 1x H100 80 GB, 61 tok/s; 8x RTX 3090, 117 tok/s). The DeepSeek 1M test used nine GPUs with tensor parallelism 8 and took 23.8 minutes to prefill 1,028,310 tokens (XenoSpectrum link above). The closest single-GPU 1M run found is an independent review on one 96 GB RTX PRO 6000 with 128 GB RAM: a 911,859-token prompt took 394 s to first token (2,312 tok/s prefill) and decoded at 46.8 tok/s: https://www.demietrich.com/blog/project_maya_review/ (read 2026-11-17). On a 3090 with 62 GB RAM, a 1M prompt would prefill far slower and the KV cache would eat RAM otherwise holding experts. Verdict on the claim: **mechanism confirmed, 1M-on-one-3090 usefulness unproven.**

## 3. NVMe traffic per token / SSD wear

**No published per-token SSD read figure for Maya was found (NOT FOUND).** What is established:

- Worst-case bound, from the architecture: GLM-5.3-Flash activates ~18 B parameters per token (README), and Maya-S24's experts are ~2-bit, so if every active weight came from SSD that would be ~4.5 GB/token. In practice hot experts live in VRAM/RAM and only cache misses hit the SSD, so real traffic is far below that bound — but the miss rate on a 62 GB-RAM box is unmeasured.
- Wear logic: SSD endurance (TBW) is consumed by **writes**, not reads. Maya reads model files (memory-mapped) and writes only logs, configs, and a one-off on-disk cache of long system prompts (v1.1.13, per the vramcalculator article). So expert streaming itself should not wear the drive. The real write risk is OS swap: Maya pins nearly all RAM, and if the system swaps, that writes to the SSD. A Strata/Maya community thread reports swap writes dropping to ~0 after setting `vm.swappiness=0`, with no speed change: https://vibingtalk.com/index.php?threads/will-strata-ruin-my-ssd.1896388/ (read 2026-11-17). **Set `vm.swappiness=0` and watch swap before worrying about the SSD.**

## 4. Build/run requirements

- **Linux x86-64, NVIDIA driver, CUDA 12.x (CUDA 13 works for RTX 20+, not V100), g++, Python 3.10+; 32 GB RAM minimum; fast NVMe, never a hard disk** (README "What you need", GitHub link above). A 3090 (sm_86) is supported; CUDA 13 Docker image covers RTX 30.
- **No official Docker image.** `docs/DOCKER.md` is a build-it-yourself recipe (`docker/build.sh`, CUDA 12 or 13); the image holds the compiled engines only — the setup does not run inside it, and running needs `--gpus all --ulimit memlock=-1` because the engines pin RAM: https://raw.githubusercontent.com/mw00/project-maya/main/docs/DOCKER.md (read 2026-11-17). No Podman instructions found.
- **No root required for the native install:** "The setup checks all of this, prints the exact command for anything missing, and installs nothing system-wide" (README). Build takes 20–40 minutes plus the ~73 GB download; `./setup.sh --model glm-maya-xs` picks the fit. (Docker itself needs the usual Docker-daemon access on the host; whether that means root on your box is a host setup question, not a Maya one.)

## 5. Verdict

**Yes — worth a 1-hour test, but test Maya-XS at 128K context, not 1M: expect ~15–26 tok/s, and treat 1M as an unproven stretch goal.**
