# Free image-to-3D and text-to-3D tools for game props — comparison for a small 2-player co-op game

**All facts read 2026-11-17 from public web pages (no login, no account, no purchase). Every fact below carries its source as a full https:// link. Where sources disagree, that is flagged rather than resolved by guessing.**

## Short answer

For 30–50 props, free, with commercial use allowed: run **Pixal3D or TRELLIS.2 locally in ComfyUI on the 24 GB GPU**, generate from a reference image (make the reference image with any free image generator for the "text-to-3D" half), then decimate in Blender to 5–15k triangles and export GLB for Godot or FBX for Unity. Both models are MIT-licensed, cost nothing per asset, and output PBR-textured GLB. No hosted free tier can cover 30–50 props: Tripo's free tier is non-commercial and ~13 models/month, Meshy's free tier allows only ~3 textured models/month and downloads only its Lite engine, and Rodin's free tier is pay-per-download. Details and caveats below.

## 1. TRELLIS and TRELLIS.2 (Microsoft Research)

- TRELLIS.2 is a 4-billion-parameter image-to-3D model released 16 December 2025; the original TRELLIS dates from December 2024 (paper, CVPR 2025 Spotlight). TRELLIS.2 is image-to-3D only; the original also takes text, but its text path is described as the weaker one. Sources: https://www.aigamer.gg/tools/trellis ; https://supavoxel.com/models/trellis-2 ; https://triposr.org/blog/trellis-2-vs-trellis
- Licence: "This model and code are released under the MIT License" (official README, quoted in secondary sources). MIT permits commercial use of what you generate. **Caveat:** the reference pipeline's render dependencies nvdiffrast and nvdiffrec are under NVIDIA's source-code licence, limited to non-commercial research/evaluation; the background remover (BRIA RMBG-2.0) is non-commercial and DINOv3 has its own licence. ComfyUI's native TRELLIS.2/Pixal3D implementation removed nvdiffrast and nvdiffrec and rewrote the post-processing in PyTorch/SciPy, and ComfyUI states there are no non-commercial dependencies in that pipeline, so generated assets can be used commercially. Sources: https://huggingface.co/microsoft/TRELLIS.2-4B ; https://trellis2.app/blog/how-to-use-trellis-2 ; https://comfy.org/pixal3d-trellis2/ ; https://www.mechnext.eu/en/article/47-trellis-2-from-one-image-to-a-3d-model-explained-for-home-creators
- Free tier: there is no credit system — the model is free to download and run; the only cost is your hardware. A hosted demo exists (Hugging Face Space) on shared-GPU quotas. Sources: https://www.aigamer.gg/tools/trellis ; https://trellis2.app/blog/is-trellis-2-free-official-pricing
- Formats: GLB with PBR materials is the main export; the reference code also exports OBJ/PLY/STL. Sources: https://huggingface.co/microsoft/TRELLIS.2-4B ; https://www.3daistudio.com/Models/Trellis-2
- Polygon counts: the reference export's decimation target defaults to 1,000,000 faces (range 100,000–2,000,000 in the Replicate deployment); guides estimate raw AI meshes at 50k–200k polygons generally. You choose the decimation target, so the count is a setting, not a fixed output. Sources: https://dev.to/aimodels-fyi/a-beginners-guide-to-the-trellis2-model-by-fishwowater-on-replicate-2hip ; https://trellis2.app/blog/how-to-use-trellis-2
- Texture quality: native PBR — base colour, roughness, metallic and opacity stored in the O-Voxel representation; textures up to 4096 px in the reference pipeline (8192 px maximum on the Replicate deployment). The exported GLB ships in opaque mode by default — transparency must be enabled in your 3D software. Generation at 512³/1024³/1536³ takes ~3 s / ~17 s / ~60 s on an H100 (authors' figures). Sources: https://triposr.org/blog/hunyuan3d-vs-trellis ; https://dev.to/aimodels-fyi/a-beginners-guide-to-the-trellis2-model-by-fishwowater-on-replicate-2hip
- Hardware: "An NVIDIA GPU with at least 24GB of memory is necessary. The code has been verified on NVIDIA A100 and H100 GPUs" and "tested only on Linux" (official README/model card). The original TRELLIS needs 16 GB. Sources: https://huggingface.co/microsoft/TRELLIS.2-4B ; https://hysenlabs.com/projects/microsoft-trellis
- Note: one independent benchmark (Nov 2026, 40 scanned objects, L40S 48 GB) measured TRELLIS.2 peaking at 37.7 GB VRAM with one object running out of memory — the 24 GB figure is the official minimum, but real-world usage can exceed it depending on resolution and export settings. Source: https://albertlieyingadrian.github.io/steerlab/experiments/image-to-3d-eval/report/

## 2. Hunyuan3D-2 / Hunyuan3D 2.1 (Tencent)

- Version 2.0 (January 2025) and 2.1 (13 June 2025). Two stages: Hunyuan3D-Shape (3.3B parameters in 2.1) builds the mesh, Hunyuan3D-Paint (2B) paints PBR textures. 2.1 replaced 2.0's RGB texture model with a PBR pipeline. Newer hosted versions 2.5, 3.0 and 3.1 exist but are hosted-only, not open weights. Sources: https://www.meshy.ai/compare/meshy-vs-hunyuan3d ; https://www.eachlabs.ai/blog/hunyuan3d-things-to-know ; https://triposr.org/blog/rodin-vs-hunyuan3d
- Licence: Tencent Hunyuan 3D 2.1 Community Licence (custom, not a standard open-source licence). Commercial use is permitted **only outside the EU, the UK and South Korea** — the licence states it does not apply in those territories. If your products/services exceed 1 million monthly active users you must request a separate licence from Tencent. Outputs may not be used to improve any AI model other than Hunyuan3D itself. You own the outputs you generate. Sources: https://agentgid.com/assets/hunyuan3d-2/ ; https://deepwiki.com/Tencent-Hunyuan/Hunyuan3D-2.1/8-licensing-and-usage
- Free tier: the open weights are free to self-host. The hosted Hunyuan 3D Engine gives 20 free generations a day on the web platform (per comparisons read 2026-10-08 and 2026-11); the Tencent Cloud API gives a one-time 200 free credits, with a standard image-to-3D call costing 25 credits. Sources: https://triposr.org/blog/rodin-vs-hunyuan3d ; https://www.meshy.ai/compare/meshy-vs-hunyuan3d ; https://the3dai.com/best-image-to-3d-ai
- Formats: GLB or OBJ export, with albedo, metallic and roughness maps saved separately; the portable app also offers PLY and STL. Sources: https://www.eachlabs.ai/blog/hunyuan3d-things-to-know ; https://klala-lab.net/en/localai-hunyuan-3d/
- Polygon counts: Tencent's own guide puts typical output at ~50k–200k polys; the octree mesh resolution is adjustable (128 fast / 256 / 512 / up to 1024). A "Simplify Mesh / Target Face Number" option exists in the app but is unavailable for textured models. Sources: https://www.tencentcloud.com/techpedia/144953 ; https://klala-lab.net/en/localai-hunyuan-3d/ ; https://www.jaiportal.com/model/hunyuan3d-2-1-quality-mode
- Texture quality: PBR (albedo, metallic, roughness; normal maps in some descriptions), 4K texture maps in the reference pipeline (paint stage renders up to 8 views at 768 px and bakes 4096 px maps). Sources: https://triposr.org/blog/hunyuan3d-vs-trellis ; https://www.bestfreewebresources.com/hunyuan3d-2-1-comfyui-guide
- Hardware: ~10 GB VRAM for shape only, ~21 GB for texture, ~29 GB for the full pipeline (Tencent's README). Runs on macOS/Windows/Linux, tested with Python 3.10, PyTorch 2.5.1, CUDA 12.4. **On a 24 GB card the full pipeline does not fit in one run — run shape (10 GB) and texture (21 GB) as separate steps.** Sources: https://www.meshy.ai/compare/meshy-vs-hunyuan3d ; https://www.bestfreewebresources.com/hunyuan3d-2-1-comfyui-guide

## 3. Tripo (hosted, VAST)

- Current models: H3.1 (High Detail, announced March 2026) and P2.0 (Smart Mesh, announced August 2026); Tripo 3.0 (20B parameters) is named in Tripo's own blog. Older open models TripoSG and TripoSR are MIT-licensed on GitHub but are not the hosted H3.1/P2 models. Sources: https://figmee.me/en/blog/tripo-ai-illustration-3d-guide ; https://www.tripo3d.ai/blog/cleaner-topology-image-to-3d ; https://www.aigamer.gg/guides/best-ai-3d-model-generators-games
- Licence: free tier models are **public and non-commercial**. Commercial use, private models and unlimited storage start at Pro. Sources: https://techpilot.ai/tools/tripo-ai/ ; https://deciderstack.com/tripo-ai-review/
- Free tier: 200 credits/month, ≈ 13 models by Tripo's estimate; 1 task at a time; 15 exports limited to the H2.5 model; 10 model storage slots; edit history 1 day. Pro is $20/month (3,000 credits, ≈ 200 models, 10 parallel tasks, meshes up to 2M polygons); Max $90/month (25,000 credits, ≈ 1,660 models, 8K textures); Team $55/seat/month billed yearly. A Best-Quality generation was observed costing 55 credits. Sources: https://techpilot.ai/tools/tripo-ai/ ; https://deciderstack.com/tripo-ai-review/ ; https://dev.to/rohanmori/tripo-ai-review-2026-i-tested-the-free-3d-model-generator-end-to-end-2ok7
- Formats: GLB, USD, FBX, OBJ, STL, 3MF. Tripo's help centre lists GLB for web/AR/VR, FBX for games and animation software, STL/3MF for printing. Sources: https://figmee.me/en/blog/tripo-ai-illustration-3d-guide ; https://www.tripo3d.ai/blog/cleaner-topology-image-to-3d
- Polygon counts: H3.1 builds detailed meshes up to 2 million polygons. One free-tier review measured a raw model at 1,012,219 vertices / 1,911,270 faces — retopology is effectively mandatory. Smart Mesh generates a clean low-poly mesh directly with a polygon count you set (8k–15k suggested for mobile NPCs; 20k polygons with Draco compression is under 1 MB as GLB). The Retopology module offers Triangle (games) or Quad Face (animation) with Auto or manual polygon count. Sources: https://www.tripo3d.ai/blog/smart-mesh-tutorial ; https://www.tripo3d.ai/blog/cleaner-topology-image-to-3d ; https://www.strayspark.studio/blog/meshy-tripo-to-godot-4-gltf-lod-normal-maps
- Texture quality: PBR textures up to 4K on Pro; 8K texture access on Max. Text-to-3D, image-to-3D, sketch and multi-view inputs; part segmentation, retopology, auto-rigging and animation for humanoids/creatures. Sources: https://affmaven.com/tripo-pricing/ ; https://figmee.me/en/blog/tripo-ai-illustration-3d-guide
- **Gotcha:** Tripo GLBs use `EXT_meshopt_compression`, which Blender's glTF importer does not support — it imports zero geometry silently. Decompress first (e.g. a meshopt decompressor) before importing to Blender. Source: https://www.meshgrab.com/blender-ai-workflow

## 6. Newer 2026 open models (beyond the five named in the brief)

- **Pixal3D** (Tsinghua University + Tencent ARC Lab, April/May 2026, SIGGRAPH 2026): image-to-3D built on the TRELLIS.2 backbone, adding pixel-aligned generation — input-image features are back-projected into 3D so the visible side of the model matches the photo closely. MIT-licensed code and weights. Native in ComfyUI core since 0.34.0; multi-view inference (up to 4 images) released 1 September 2026 and in ComfyUI from 8 September 2026. Peak VRAM ~18 GB standard, 10–12 GB low-VRAM mode. GLB with PBR textures. It was the most-downloaded open 3D model in ComfyUI in the 30 days before the comparison read (806,174 downloads). Sources: https://comfy.org/pixal3d-trellis2/ ; https://www.scriptbyai.com/best-free-ai-image-to-3d-generators/ ; https://comfyui-wiki.com/en/news/2026-09-09-pixal3d-multiview ; https://www.creativeainews.com/articles/best-open-source-ai-3d-models-2026/
- **Idol** (Speridlabs, 28 October 2026): Apache 2.0, single image → 3D Gaussian splat (.ply), up to 1,048,576 Gaussians, 7.2 GB peak VRAM, ~19 s on an RTX 4090 for 262,144 Gaussians. **Not a mesh** — a Gaussian splat cannot go straight into Godot/Unity physics or standard mesh pipelines; it needs conversion or a splat renderer. It also requires accepting gated terms for two encoders (Meta DINOv3, Black Forest Labs FLUX.2 VAE) on Hugging Face before the first run. Sources: https://www.explainx.ai/blog/speridlabs-idol-image-to-3d-gaussian-splat-open-model-2026 ; https://af.net/realtime/speridlabs-releases-idol-image-to-3d-model-with-1m-gaussians/
- **SPAR3D** (Stability AI, 2025): feedforward single-image mesh reconstruction, improves on Stable Fast 3D by conditioning on a point cloud (better backsides). Stability AI Community Licence (free commercial use under $1M annual revenue). GLB output, ~10.5 GB VRAM default, ~7 GB low-VRAM mode, with `--remesh_option` (None/Triangle/Quad) and `--texture-resolution` flags. Sources: https://raw.githubusercontent.com/Stability-AI/stable-point-aware-3d/main/README.md ; https://www.creativeainews.com/articles/best-open-source-ai-3d-models-2026/
- **Stable Fast 3D** (Stability AI): sub-second generation (~0.5 s), UV-unwrapped textured mesh, ~6–7 GB VRAM, GLB only, Stability AI Community Licence. Good for fast drafts, lower fidelity than TRELLIS.2/Hunyuan3D. Sources: https://o-mega.ai/articles/ai-image-to-3d-the-complete-2026-guide ; https://www.the3dai.com/best-image-to-3d-ai
- **TripoSR** (Tripo + Stability AI): MIT, single image → mesh in under 0.5 s on an A100, ~6 GB VRAM with CPU fallback. Vertex colours only (no PBR) unless the bake-texture option is used; OBJ/GLB output. Best as a fast, light draft model, not for final textured props. Sources: https://hysenlabs.com/projects/vast-ai-research-triposr ; https://triposr.org/blog/hunyuan3d-vs-trellis
- **Step1X-3D**: Apache 2.0 (listed among the permissively licensed open models in the 2026 survey). VRAM, formats and output quality were not confirmed in the sources read — see Unsure about. Source: https://www.creativeainews.com/articles/best-open-source-ai-3d-models-2026/
- Also named in the 2026 survey but not detailed here (insufficient verified detail in sources read): Direct3D-S2 and UltraShape (Apache 2.0), TripoSG/TripoSplat (MIT, splat/mesh), SAM 3D Objects/Body (Meta SAM Licence). Source: https://www.creativeainews.com/articles/best-open-source-ai-3d-models-2026/

## 7. Which run locally on a 24 GB GPU, and which on Colab?

**Local 24 GB GPU (e.g. RTX 3090/4090, 24 GB):**

- TRELLIS.2: yes, 24 GB is the official minimum (Linux only for the reference pipeline; the ComfyUI native build is the friendlier route). Expect tight VRAM at 1536³ — use 512³/1024³ for props.
- Pixal3D: yes, ~18 GB peak (10–12 GB low-VRAM).
- Hunyuan3D 2.1: shape-only yes (10 GB); texture stage yes (21 GB); **full pipeline in one run no (29 GB)** — run the stages separately.
- TripoSR / Stable Fast 3D / SPAR3D: yes, comfortably (6–10.5 GB).
- Idol: yes (7.2 GB) — but output is a splat, not a mesh.
- Tripo / Meshy / Rodin: hosted; no local GPU needed at all.
- Sources: https://huggingface.co/microsoft/TRELLIS.2-4B ; https://www.scriptbyai.com/best-free-ai-image-to-3d-generators/ ; https://www.meshy.ai/compare/meshy-vs-hunyuan3d ; https://raw.githubusercontent.com/Stability-AI/stable-point-aware-3d/main/README.md ; https://hysenlabs.com/projects/vast-ai-research-triposr

**Google Colab:**

- Free Colab gives an NVIDIA T4 (16 GB) "subject to quota restrictions and availability", with no published quota; sessions up to 12 hours. The T4 is the only free GPU. Paid compute units ($9.99 per 100, or Pro $9.99/month) unlock the L4 (24 GB, ~1.5–1.7 units/hour) and A100 (40/80 GB, ~5.3–5.4 units/hour). Since August 2026, H100/G4 are Pro+ only. Sources: https://fastero.com/blog/google-colab-gpu ; https://freakyjolly.com/google-colab-free-gpu-limits/
- Consequences: TRELLIS.2 (24 GB minimum) **does not fit free Colab** — it needs a paid L4. Hunyuan3D shape-only (10 GB) fits a free T4; the full pipeline needs a paid A100. TripoSR, Stable Fast 3D and SPAR3D (6–10.5 GB) fit a free T4. Pixal3D low-VRAM mode (10–12 GB) should fit a free T4, but this was not confirmed by a run — see Unsure about.
- Kaggle is a free alternative worth knowing: ~30 GPU hours/week, T4 x2 or P100, 12-hour sessions. Source: https://freakyjolly.com/google-colab-free-gpu-limits/
- Note: Colab's free tier blocks hosting web UIs (e.g. a ComfyUI interface through a tunnel) without a paid compute balance, so run headless scripts on free Colab. Source: https://freakyjolly.com/google-colab-free-gpu-limits/

## 8. Typical cleanup steps to get props into Godot or Unity

Raw AI meshes are dense triangle soup (often 50k–2M faces), non-manifold, with the origin floating and textures baked at high resolution. None of the tools above ships a game-ready prop. The standard pass, done in Blender (free), is:

1. **Import the GLB** (File > Import > glTF 2.0). GLB carries geometry, PBR materials and textures in one file; OBJ needs manual MTL re-linking and STL drops UVs entirely. Sources: https://www.voxelvia3d.app/blog/blender-ai-3d-model-workflow ; https://www.meshgrab.com/blender-ai-workflow
2. **Inspect and repair**: check for holes, non-manifold edges, floating parts and inverted normals; delete interior/hidden geometry; merge duplicate vertices. (Blender: Edit Mode > Select > Select All by Trait, Mesh > Clean Up.) No single source read gives a complete repair checklist — this step is standard practice, not a quoted procedure.
3. **Decimate to budget**: Decimate modifier (Collapse mode) at ratio ~0.1 cuts ~90% of faces (e.g. 145k → ~7.2k tris) while keeping UVs, because decimation removes edges without rebuilding the surface, so surviving vertices keep their UV coordinates. For broken/intersecting meshes, voxel remesh first, then quad remesh; for deforming characters, hand retopology. Practical prop budgets from pipeline presets: Godot 4 prop 10,000 tris, Unity 6 prop 15,000 tris, web/glTF prop 6,000 tris; mobile wants less. Sources: https://www.voxelvia3d.app/blog/blender-ai-3d-model-workflow ; https://www.strayspark.studio/blog/reduce-polycount-ai-3d-model-blender-decimate-vs-remesh ; https://www.meshgrab.com/blender-ai-workflow
4. **Fix the origin and scale**: move the origin to the bottom-centre of the object so it sits on the ground instead of spawning half-buried; set real-world units (1 unit = 1 m). Tripo's export has a "Bottom-Center Pivot" toggle that does this at export time. Sources: https://www.voxelvia3d.app/blog/blender-ai-3d-model-workflow ; https://www.tripo3d.ai/blog/cleaner-topology-image-to-3d
5. **Smooth shading and normals**: Shade Smooth on everything; add an Edge Split / sharp-edge pass where needed. If you remeshed (new UVs), bake a normal map from the high-poly original onto the low-poly mesh. Sources: https://www.meshgrab.com/blender-ai-workflow ; https://www.strayspark.studio/docs/meshprep
6. **Fix texture colour spaces**: on glTF import, set normal/metallic/roughness textures to Non-Color (Blender defaults them wrong). Check the base-colour map for baked-in lighting/shadows — AI textures often bake the lighting of the reference photo; if it looks wrong under engine lighting, re-texture or accept it for stylised props. Source: https://www.meshgrab.com/blender-ai-workflow
7. **Shrink textures**: 4K maps are overkill for small props — resize to 1K or 2K (and use Draco compression on GLB export) to keep build size down. Source: https://www.tripo3d.ai/blog/how-to-optimize-a-3d-model-polygons-textures-ai
8. **Export for the target engine** (File > Export > glTF 2.0, with Apply Modifiers checked):
   - **Godot 4**: GLB/glTF 2.0 is the **recommended** format; Godot auto-generates LODs on import for glTF/FBX scenes. OBJ is not recommended — it has no PBR materials, no UV2 and no auto-LOD. FBX works via ufbx (default since Godot 4.3). Godot reads normal maps in the OpenGL convention. Sources: https://www.strayspark.studio/blog/meshy-tripo-to-godot-4-gltf-lod-normal-maps ; https://ludo.ai/docs/3d-generator/export-to-unity-godot-unreal
   - **Unity**: FBX is native — drag into Assets and Unity imports mesh, materials and textures and creates a prefab. **GLB needs the glTFast package** (`com.unity.cloud.gltfast` via Package Manager); stock Unity does not recognise .glb. For URP projects, convert imported Standard materials to URP Lit (Edit > Rendering > Materials > Convert Selected). Rigged FBX: set Animation Type to Humanoid. Sources: https://docs.3daistudio.com/integrations/unity ; https://ludo.ai/docs/3d-generator/export-to-unity-godot-unreal ; https://www.selfcad.com/blog/from-glb-to-production-getting-web-and-ai-generated-models-into-3ds-max-maya-and-unity
9. **Collision**: AI meshes have no collision shapes. In Godot, add a simple collision shape (box/capsule/convex) rather than using the render mesh; in Unity, generate a convex Mesh Collider or use primitive colliders. (Standard engine practice; no source read states this for AI meshes specifically.)
10. **Batch it**: the per-prop pass is ~3–20 minutes by hand. For 30–50 props, script it — Blender's Python API in headless mode can import each GLB, apply Decimate, fix the origin, and re-export in a loop. Source: https://www.meshgrab.com/blender-ai-workflow

## 9. Recommendation: one free pipeline for 30–50 props

**Recommended: Pixal3D (first choice) or TRELLIS.2 (fallback) in ComfyUI, local 24 GB GPU → Blender decimate → GLB (Godot) / FBX (Unity).**

Why this one:

- **Truly free at volume.** No credits, no monthly cap, no per-model fee — the only cost is electricity and your time. At 30–50 props, every hosted free tier fails on volume or licence: Tripo free is non-commercial and ~13 models/month (4 months for 50 props, and you still could not ship them); Meshy free allows ~3 textured models/month and blocks Meshy 6/7 downloads entirely; Rodin free is pay-per-download (~$1.50/credit) and its free-tier commercial status is unresolved. Sources: sections 3–5 above.
- **Cleanest licence for a commercial game.** MIT, code and weights, with ComfyUI's native build removing the two non-commercial NVIDIA dependencies. Pixal3D shares the TRELLIS.2 backbone and licence. Hunyuan3D 2.1 is the quality rival but its licence excludes the EU/UK/South Korea outright — a real problem if the game is sold on Steam worldwide. Sources: https://comfy.org/pixal3d-trellis2/ ; https://deepwiki.com/Tencent-Hunyuan/Hunyuan3D-2.1/8-licensing-and-usage
- **Best output for the job.** Native PBR (base colour, roughness, metallic, opacity) in a single GLB, up to 4096 px textures, and Pixal3D's pixel alignment keeps the visible side faithful to your reference image — useful when props must match concept art. Sources: https://triposr.org/blog/hunyuan3d-vs-trellis ; https://comfy.org/pixal3d-trellis2/
- **Fits the hardware.** Pixal3D ~18 GB peak (10–12 GB low-VRAM); TRELLIS.2 24 GB minimum at reference settings — run at 512³/1024³ for props rather than 1536³. Sources: https://www.scriptbyai.com/best-free-ai-image-to-3d-generators/ ; https://huggingface.co/microsoft/TRELLIS.2-4B
- **Text-to-3D workaround.** Neither model takes text directly (TRELLIS.2 is image-only). Generate a reference image first with any free image model, then run image-to-3D. For a prop pipeline this is arguably better anyway: the reference image fixes the art direction, and Pixal3D preserves it.

Concrete pipeline:

1. Make one clean reference image per prop (single object, plain background, front three-quarter view). Batch-generate with a free image model or draw from concept art.
2. Run Pixal3D (or TRELLIS.2) in ComfyUI on the 24 GB GPU, 1024³, texture 2048 px, decimation target ~100k faces at export. Expect ~1–2 minutes per prop including export (generation is seconds; GLB export/remeshing is the slow part — one benchmark measured 15 minutes per object for TRELLIS.2 GLB export at the 500k-face default, so use the smallest face target). Source: https://albertlieyingadrian.github.io/steerlab/experiments/image-to-3d-eval/report/
3. Blender batch script: import GLB → Decimate to 5–15k tris → origin to bottom-centre → Shade Smooth → fix texture colour spaces → resize textures to 1K/2K → export GLB (Godot) or FBX (Unity). Spot-check 3–4 props by hand before batching the rest.
4. Import, add simple collision shapes, and set up one shared material/naming convention (`SM_` prefix, one folder per prop).

If there is no local 24 GB GPU: use paid Colab L4 (~$10/month Pro, ~1.5 units/hour) for the same pipeline, or — if $20/month is acceptable — one month of Tripo Pro ($20, 3,000 credits ≈ 200 models, commercial, Smart Mesh + Retopology built in) covers all 50 props in a weekend. That is the fastest paid fallback, not the free recommendation.

## Unsure about

- **Rodin free-tier commercial rights.** One source (3dtoolwiki) says commercial rights are included on every tier including free downloads; another (respawnstack, quoting Hyper3D's pricing page) says the free plan does not list "any use", and a third (picassoia) says the pricing page spells out a commercial licence only for Business. The Hyper3D pricing page itself was not directly read. Do not ship free-tier Rodin output in a paid game until the licence badge on the asset or the terms page is checked. Sources: https://3dtoolwiki.com/tools/rodin ; https://respawnstack.com/guides/meshy-vs-tripo-vs-rodin ; https://blog.picassoia.com/rodin-gen-2-5-hyper3d-image-to-3d-pricing-and-quality
- **Hunyuan3D hosted free allowance.** Comparisons read give "20 free generations a day" for the hosted platform, but one comparison (aigamer.gg, Nov 2026) says the hosted free allowance is "not confirmed". The 200-credit API figure comes from Meshy's comparison page. Treat 20/day as reported, not verified against Tencent's own page.
- **TRELLIS.2 real-world VRAM.** The official minimum is 24 GB, but an independent benchmark measured 37.7 GB peak on a 48 GB L40S and one out-of-memory failure. Whether a 24 GB card succeeds depends on resolution, face target and export settings; 512³/1024³ with a low face target is the safe zone, but I have not verified this by running it.
- **Pixal3D on free Colab T4.** Low-VRAM mode is reported at 10–12 GB, which should fit a 16 GB T4, but no source read confirms a successful free-Colab run; Colab also blocks web-UI tunnels on the free tier, so it would need headless execution.
- **Step1X-3D details.** Only its Apache 2.0 licence was confirmed in the sources read; VRAM, formats, poly counts and texture quality were not found. It is listed here for completeness, not as a verified recommendation.
- **Meshy 6/7 download block on the free tier.** Meshy's own blog and pricing page agree downloads are Lite-only on free, but Meshy's help centre wording (quoted by a third party) says free accounts cannot download generated models at all, apart from the small Lite allowance. The practical reading is the same — do not plan a Meshy-free pipeline around downloading Meshy 6/7 models.
- **Exact raw polygon counts** for TRELLIS.2, Hunyuan3D 2.1, Rodin, SPAR3D and Stable Fast 3D outputs are not published as fixed numbers; counts depend on resolution/decimation/remesh settings, so the figures above are settings and ranges, not guarantees.
- **Tripo free-tier export limit.** Sources agree on 15 exports (H2.5 only) but one source lists "10-model storage" and another "15 exports" — both are quoted; the binding limit for a 30–50 prop run is the non-commercial licence, not the export count.
