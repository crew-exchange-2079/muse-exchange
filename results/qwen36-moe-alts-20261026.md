## Headline finding: no independent benchmark exists for any candidate

No candidate below has a verified Artificial Analysis, LiveBench, BenchLM, or Aider score for the exact model listed. ## Top 2 picks

### (a) Coding agent work

1. **Ornith 1.5 35B-A3B** — Highest self-reported coding numbers of any candidate (SWE-bench Verified 79.0, Terminal-Bench 2.1 67.8, both above Qwen 3.6's publisher-reported 73.4 / 51.5), with a publisher GGUF whose Q4 (21.7 GB) fits 24 GB — but the numbers are self-reported only, so the test must verify them.
2. **K2-Horizon MoVA 36B-A4B** — The only candidate with a documented RTX 3090 run (41 tok/s at Q4_K_M) plus a third-party BigCodeBench-Hard run (27.3%), and self-reported Terminal-Bench 2.1 58.6; the Q4 fit is tight (22.37 GB) and stock llama.cpp initially rejected the architecture, so budget setup time.

Closest alternate for coding: Xing4.0 (self-reported SWE-bench Verified 75.00, Terminal-Bench 2.1 57.50) — held back by out-of-tree vLLM/SGLang plugins and a community-only GGUF with unverified Q4/Q5 sizes.

### (b) General chat / tool calling

1. **LFM2.5 24B-A2B** — The only comfortable 24 GB fit in the list (Q4_K_M 14.95 GB leaves real KV-cache headroom), with self-reported tool/agent numbers (IFEval 96.75, IFBench 74.69, LiveClaw 48.09) — but it carries a vendor-specific license (lfm1.0, not Apache/MIT) and self-reported-only benchmarks.
2. **MiniCPM-V 4.7 35B-A3B** — Q4_K_M 22 GB, Apache 2.0, established publisher (OpenBMB), multimodal, with an EXL3 option at 18.0 GB — but its "beats Qwen 3.6" claim has no numeric benchmark table behind it, so it is self-reported in the weakest form.

Closest alternate for general/agent work: Sage-A1.5 (self-reported GAIA 95.1, BrowseComp 81.7) — held back only by the <7-day age flag (released ~2026-10-21); re-check it in a week once independent runs appear.

## Red flags (whole list)

- **Released <7 days before 2026-10-26 (i.e. after ~2026-10-19):** Flint (2026-10-21), Raon-1 mini preview (2026-10-21), Sage-A1.5 (~2026-10-21). All three are also self-reported-only.
- **Benchmarks self-reported only (no independent score):** all 12 candidates. The only third-party numbers anywhere are two small community runs (Ornith BigCodeBench-Hard 27.0%, K2 BigCodeBench-Hard 27.3%) and one small independent test (MiniCPM-V paperwork-v3 22.2% / 11.1%).
- **No license / non-standard license:** LFM2.5 uses vendor license lfm1.0 (not Apache/MIT). All others state Apache-2.0 or MIT, though Ornith's MIT and Nex's Apache-2.0 rest on secondary confirmation, not a primary HF metadata read.
- **Unknown / obscure publisher:** Tiel Coder (individual account peculiar-ragdoll); BigBang-v1's Endless Frontier is a newer, smaller lab; Apodex is a smaller, newer vendor (named company, but thin independent verification for the mini).
- **24 GB fit problems:** Flint Q4 (25.35 GB) exceeds 24 GB before KV cache; K2 Q4 (22.37 GB) and MiniCPM/Apodex/Sage Q4 (~21.7–22 GB) leave almost no KV headroom at long context; Raon and Xing Q4 sizes are unverified; Nex has no verified 24 GB CUDA path at all (official baseline 2× H100, custom SGLang fork).
- **Runtime immaturity:** K2 (stock llama.cpp initially rejected the architecture; trust_remote_code needed for safetensors path); Xing4.0 (vLLM/SGLang support only as out-of-tree plugins; trained on Ascend NPUs with MindSpore); Nex-N2.5-mini (custom SGLang fork required); Raon-1 mini is a preview release with gated repos (access on request).
- **Misattribution traps found and avoided:** Artificial Analysis 44 belongs to full Apodex 1.1, NOT the mini; Raon's "AA-Omniscience" rows are vendor runs on AA datasets, not AA scores; bartowski's GGUF is for Nex-N2-mini, NOT Nex-N2.5-mini; Ornith's ~545 tok/s claim is a custom M3TiS build, not GGUF speed.
