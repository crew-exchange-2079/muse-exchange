# Self-hosted agent memory vs Postgres keyword search — for a small fleet of coding agents sharing facts via MCP

Read date for every fact: 2026-10-26. Context: the team's own blind test found keyword search beat embedding search, so the bar for any challenger is beating tsvector, not embeddings. Option 4 pick: **Graphiti** — the only candidate with first-class per-fact validity windows (valid_at/invalid_at), which is exactly the fact-supersession problem, with an in-repo MCP server; Letta's unit is an editable memory block (overwrite, no per-fact window) and mem0's vector store and graph can drift out of sync with no way to tell which fact is current.

## Verdict

1. No option is clearly better than Postgres keyword search for this small fleet: the team's own blind test already favors tsvector, and none of the challengers has an independent benchmark win on team-style fact questions.
2. Hindsight is the closest challenger — same Postgres-only footprint as the incumbent, a built-in default-on MCP server, reversible supersession, and the strongest published numbers — but its headline scores are vendor/paper runs on conversational benchmarks, not on shared fleet facts.
3. Graphiti has the best supersession model (true point-in-time queries), but it adds a graph DB, per-episode LLM extraction cost, an experimental MCP server, and an independent LoCoMo result that runs against it.
4. Beacon solves a different problem (human-reviewed session traces → reusable skills, project-scoped) and is not a shared fact store; adopt it only if the fleet's need is lesson reuse, not fact lookup.
5. The A/B test that would prove a challenger: freeze ~100 real fleet questions (host facts, decisions, prior work, including 20 about facts known to have changed); run Postgres tsvector and the challenger blind, side by side, for 2–4 weeks of real sessions; score correctness, stale-fact rate (superseded facts returned as current), and p95 latency; a challenger wins only if it beats tsvector on correctness AND stale-fact rate without worse latency or ops burden.
