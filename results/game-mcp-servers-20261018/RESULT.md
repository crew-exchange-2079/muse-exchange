# game-mcp-servers-20261018

Task: find every working way an AI coding agent (Claude Code, Codex, Cursor) can directly control a game engine or 3D tool in 2026 — MCP servers, plugins and bridges for Unreal Engine 5, Unity 6, Godot 4, Blender and Three.js/web tooling, with a top pick per engine and demos of agents building real scenes.

Read date for all pages: 2026-10-18. Public pages only. Stars and commit dates are exactly as shown on each repo page on the read date.

## Bottom line

Every major engine now has a working MCP bridge, and two vendors have gone first-party: **Epic ships an official Unreal MCP inside UE 5.8**, and **Unity ships an official MCP server with its AI Assistant package** (subscription-gated). The community leaders are bigger than most people realise — CoplayDev's Unity MCP has ~15,000 GitHub stars, ahujasid's Blender MCP ~31,400, and Coding-Solo's Godot MCP ~6,100. The exception is Three.js itself: there is **no official or scene-editor-grade Three.js MCP** — agents write Three.js code and verify it through browser MCPs (Playwright MCP, Chrome DevTools MCP), while the one strong web-native editor MCP is PlayCanvas's official one. Health warnings matter in this field: the most famous early Unreal server (chongdashu) has had no commits since April 2025, and one widely-cited Godot repo (Natfii/UnrealMCP) doesn't exist — details below.

## Top pick per engine

- **Unreal Engine 5 — Epic's official Unreal MCP** if you're on UE 5.8: it's first-party, ships in the editor, and covers actors/Blueprints/assets/Niagara/Sequencer with Epic maintaining it. On 5.5–5.7, **ChiR24's EngineWire** is the community pick — the broadest capability set (~400 operations including PIE testing and model-visible screenshots), token-secured, and the most actively developed (2,700+ commits). flopperam's hosted Flop MCP is the pick if you want one-prompt world-building demos rather than low-level control.
- **Unity 6 — CoplayDev/unity-mcp.** The most-starred (15,068★), MIT, works from Unity 2021.3 through 6.x, actively released (v10.3.0, Oct 2026), and covers the full loop: scene/GameObject editing, Roslyn-checked script edits, console reading, play mode, tests, builds, even light baking. IvanMurzak's is the alternative if you need screenshots, reflection calls, or MCP *inside a compiled build*. Unity's official server is the safe corporate choice but is gated behind Unity Cloud + an AI subscription/trial.
- **Godot 4 — hi-godot/godot-ai** for capability (46 tools, screenshots, one-click client setup, very active), with two cautions: it needs Godot 4.7+ on its current line, and its **telemetry is on by default** — set the opt-out env var. Coding-Solo/godot-mcp is the simpler, most-starred alternative if you don't need screenshots/input; Godot MCP Pro ($15) or hybridindie/godot-mcp (194 tools, updated Oct 17, 2026) if you need input simulation and runtime inspection.
- **Blender — ahujasid/mcp-for-blender.** 31,438 stars, MIT, actively maintained, and the only one with a full loop: build → Poly Haven/AI-generated assets → multi-angle viewport verification. The **official Blender Lab server** is the conservative alternative for analysis/scripting/debugging — small toolset, and it carries Blender's own warning that LLM code runs unguarded.
- **Three.js / web — there is no Three.js pick, and that's the finding.** Agents control Three.js the way they control any web app: write the code, then verify with **Playwright MCP** (canvas screenshots, console errors) and **Chrome DevTools MCP** (performance traces). If you want an agent driving a real web-3D *editor*, **PlayCanvas's official Editor MCP** (~130 tools incl. runtime screenshots and input) is the only mature option; threlte-mcp gives live scene control only inside Threlte/Svelte projects.

## How I checked it

- Every tool in the main tables had its actual GitHub repo page (or official vendor page) opened and read on 2026-10-18; capabilities are from each project's own README/docs, versions/OS from its stated requirements, and stars/forks/commit counts exactly as displayed.
- Existence checks caught real errors in common citations: `Natfii/UnrealMCP` 404s (the project is UnrealClaude), `justinpbarnett/unity-mcp` redirects to CoplayDev, IvanMurzak's license is Apache-2.0 (not MIT as older roundups claim), and the DmitriyGolub Three.js DevTools repo 404s despite its registry listing.
- Where a repo's commits page didn't render an explicit HEAD date, the entry says so and reports the dated evidence available (release versions/dates) instead of estimating.
