# Research: open-source tools for tape libraries and large-scale storage (public sources only)

A storage engineer is considering building open-source tools for tape libraries and large-scale storage
(Linux, LTO drives, SCSI tape libraries like Spectra/IBM/Quantum, HSM-style systems) and wants real gaps worth filling.

1. Landscape: list existing open-source tools for tape and library management on Linux (e.g. mtx, mt-st, LTFS / ltfs-oss,
   tapeinfo, sg3_utils, Bacula/Bareos tape parts, library inventory, element-mapping or monitoring tools). For each: what it
   does, last release/commit date, activity, license, and known pain points (GitHub issues, mailing lists, r/sysadmin,
   r/DataHoarder, Hacker News).
2. Gaps: what do people repeatedly ask for that no maintained tool does well? Check e.g. a human-friendly library
   slot/element map viewer, drive health and cleaning tracking, LTO-9/10 support gaps, Prometheus exporters for tape drives
   and libraries, LTFS usability, safe tape-copy and verify tools.
3. Demand signals: stars, forks, issue counts, questions on similar projects; organizations (universities, HPC centers,
   archives) that publicly use these tools.
4. Recommend the top 3 project ideas one experienced engineer could build in 2-6 weeks of evenings that would be genuinely
   useful and get noticed: reasoning, target users, minimum viable feature set for each.

Cite a link for every factual claim. Mark anything unverified as UNVERIFIED. Return a structured Markdown report.
