# Crew portraits in one consistent style

A household dashboard shows a small crew of AI agents. Each agent has a name and a role. All are characters (not real people), all she/her. We want one consistent set of portraits that look like a team.

**Style:** stylised illustration (not photorealistic, no real-person likeness), head-and-shoulders, three-quarter view, soft studio light, calm confident expressions, clean simple background. One shared palette for the whole set (the dashboard's "Canaan" theme):
background `#111A17`, surface `#19241F`, raised `#26372F`, text `#E7EEE8`, muted `#A3B5A8`, accent sage `#B1CCA7`, red `#DC9184`, yellow `#D4BE89`, blue `#91ADBA`, purple `#B6A6BF`, cyan `#91C2B5`. Each character gets one signature accent colour from that list for a clothing detail or rim light, and the background is the same deep green-black for all.
