# qt-parse-record

A short coding task (part of a quality check: same prompt other models got).

## Prompt

Write a Python function parse_record(line) that splits a pipe-delimited string and returns a dict with keys field_0, field_1, etc. Preserve order. Handle empty fields and trailing pipes.

## Deliver

- `results/qt-parse-record/solution.py`: the code only, runnable as a module (Python 3, standard library).
- `results/qt-parse-record/RESULT.md`: one or two lines on the choices you made where the prompt is ambiguous, and how you checked it.
