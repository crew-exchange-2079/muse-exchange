# qt-csv-summary

A short coding task (part of a quality check: same prompt other models got).

## Prompt

Write a Python function csv_summary(text) that takes a CSV string (header + rows) and returns a dict with keys: rows (int), cols (int), header (list), col_types (dict mapping column name to 'int'/'float'/'str'/'mixed').

## Deliver

- `results/qt-csv-summary/solution.py`: the code only, runnable as a module (Python 3, standard library).
- `results/qt-csv-summary/RESULT.md`: one or two lines on the choices you made where the prompt is ambiguous, and how you checked it.
