# qt-bounded-counter

A short coding task (part of a quality check: same prompt other models got).

## Prompt

Write a Python class BoundedCounter with __init__(max), add(n), remove(n), and a count property. Count must stay in [0, max].

## Deliver

- `results/qt-bounded-counter/solution.py`: the code only, runnable as a module (Python 3, standard library).
- `results/qt-bounded-counter/RESULT.md`: one or two lines on the choices you made where the prompt is ambiguous, and how you checked it.
